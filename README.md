\# 🎥 AI Video Verification System



This project verifies AI-generated videos using a hybrid approach that combines \*\*digital provenance (watermark-based authentication)\*\* and \*\*deepfake detection\*\*.



---



\## 📌 Problem Statement



With the rise of Generative AI models capable of producing highly realistic videos, distinguishing between real and AI-generated media has become increasingly difficult. Traditional deepfake detection methods are unreliable under real-world conditions and often produce false positives.



---



\## 💡 Solution Overview



This system follows a \*\*two-stage verification pipeline\*\*:



1\. \*\*Proactive Verification (Digital Provenance)\*\*  

&nbsp;  - Checks whether a video was generated by a compliant AI system  

&nbsp;  - Uses cryptographic hashing and a provenance registry  

&nbsp;  - Deterministic and reliable  



2\. \*\*Reactive Verification (Deepfake Detection)\*\*  

&nbsp;  - Applies a deep learning–based classifier when provenance is absent  

&nbsp;  - Produces a probabilistic result with explicit low-confidence warnings  



---



\## 🧠 Key Insight



> Deepfake detection alone is unreliable under domain shift.  

> Proactive provenance verification provides stronger guarantees for authenticating AI-generated media.

\## 🏗️ System Architecture



Video Upload

│

├── Provenance Check (Hash-based Watermark Registry)

│ └── Verified AI-generated

│

└── Deepfake Detection (Fallback)

└── Likely Real / Likely AI-generated (Low Confidence)Video Upload



---



\## 🛠️ Technologies Used



\- Python

\- PyTorch

\- Streamlit

\- OpenCV

\- SHA-256 Cryptographic Hashing



---



\## 🚀 Deployment



The system is deployed using \*\*Streamlit Cloud\*\* and supports real-time video verification through a web interface.



---



\## ⚠️ Limitations



\- Deepfake detection is probabilistic and may produce false positives

\- Provenance verification requires cooperation from the AI generator

\- Neural watermark embedding at generation time is assumed but not implemented



---
